# MovieTicketsBooking
# 🎬 Movie Ticket Booking System (CLI-Based)

This is a **command-line interface (CLI)** Python application for a Movie Ticket Booking System that allows users to register, log in, browse movies and screenings, and book movie tickets. It connects to a MySQL database using `pymysql`.

---

## 🚀 Features

- ✅ Customer Signup and Login (with secure password input)
- 🎥 View currently showing movies
- 🕐 View upcoming screenings
- 🎟️ Book tickets and calculate total fare
- 📋 View your previous bookings
- 💾 MySQL database connectivity
- 🔐 Password input hidden using `getpass`

---

## 🛠️ Technologies Used

- Python 3.x
- MySQL 8.x
- [PyMySQL](https://pypi.org/project/PyMySQL/) (for database access)
